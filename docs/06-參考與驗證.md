# 06｜參考來源與驗證範圍

## 內容來源

本教材不是原 HackMD 的逐字拷貝；以零程式基礎大學生為對象重寫，補上安裝、GitHub 登入、建立私有庫、邀請協作者、clone、正式 Review、合併與同步。

- [原始 HackMD：Git／GitHub](https://hackmd.io/UNOduc7MTTiZYFzy9pgdsw)：Feature Branch、Atomic Commit、PR／Code Review、restore／revert 的課程主軸與 task-status.txt 情境。
- [GitHub Hello World](https://docs.github.com/en/get-started/using-github/hello-world)：repo、分支、PR 與合併流程。
- [Git switch](https://git-scm.com/docs/git-switch)：建立與切換分支。
- [Git restore](https://git-scm.com/docs/git-restore)：工作目錄還原與取消暫存的差異。
- [Git revert](https://git-scm.com/docs/git-revert)：以反向提交保留原本歷史。
- [GitHub Commit 信箱設定](https://docs.github.com/en/account-and-profile/how-tos/email-preferences/setting-your-commit-email-address)：個別專案設定與 noreply 信箱。
- [gh auth login](https://cli.github.com/manual/gh_auth_login)、[gh repo create](https://cli.github.com/manual/gh_repo_create)、[gh pr create](https://cli.github.com/manual/gh_pr_create)、[gh pr review](https://cli.github.com/manual/gh_pr_review)、[gh pr merge](https://cli.github.com/manual/gh_pr_merge)：GitHub CLI 操作參考。

官方文件查閱日期：2026-11-02。GitHub 網頁文案可能因語系、版面與 repo 規則不同而略有差異，以功能名稱與畫面提示為準。

## 驗證範圍

教材製作時已在隔離資料夾以 PowerShell 和 Git 試跑：初始化、首次提交、建立分支、暫存區差異、restore、已推送錯誤與 revert、clone、fetch、合併和 fast-forward 同步。遠端傳輸以本機 bare repo 模擬，檢查狀態與歷史是否符合教材。

2026-11-02 驗證結果：

| 情境 | 結果 |
| --- | --- |
| 標準主線：四筆練習 Commit＋合併 | 通過；main 為 todo、包含說明檔、工作目錄乾淨 |
| Review 後補一筆修正再同步與合併 | 通過；審查者可取回修正，保留完整六筆歷史 |
| 暫存區 doing、工作檔 BROKEN、HEAD todo | 通過；取消暫存保留 BROKEN |
| restore／已推送後 revert | 通過；前者不新增 Commit，後者保留錯誤與反向提交 |
| 備份及 PR 草稿排除追蹤 | 通過；不混入提交 |
| 文件內部連結與程式碼區塊 | 已檢查 |

GitHub 帳號授權、repo 建立、邀請協作者、PR／Review 與 GitHub 端合併需要真實帳號及權限。這些指令依官方文件編寫，不宣稱已代替學生實際在 GitHub 執行。教材庫發布在 robylin829/git-team-practice；發布教材不代表已替學生完成課程演練。正式上課前，教師應用測試帳號走一次完整 GitHub 流程。
