# 00｜安裝、帳號、終端機

目標：看懂在哪裡輸入指令，並讓自己的電腦能和 GitHub 溝通。完成後才進入學生手冊。

## 1. 認識這次會用到的工具

| 名稱 | 白話說明 | 你會拿它做什麼 |
| --- | --- | --- |
| Git | 電腦上的版本紀錄工具 | 記錄每次修改、比較、回復 |
| GitHub | 網路上的協作平台 | 放遠端專案、開 PR、互相 Review |
| GitHub CLI，指令叫 gh | 操作 GitHub 的工具 | 登入、建立儲存庫、送 PR |
| PowerShell 7 | 接受文字指令的終端機 | 輸入本教材的所有指令 |

「儲存庫 repository，簡稱 repo」是專案加上版本紀錄；「Commit」是一次有說明的存檔點。Git 和 GitHub 是不同東西，只有 Commit 還沒有上傳。

## 2. 建立自己的 GitHub 帳號

1. 開啟 [GitHub](https://github.com)，選擇 Sign up；已有帳號直接 Sign in。
2. 依畫面完成信箱驗證。使用自己的帳號，記下使用者名稱，不把密碼交給同學。
3. 右上角頭像 → Settings → Emails，開啟 Keep my email addresses private。
4. 複製畫面上自己的 `noreply` 信箱，稍後用於 Commit 署名。不要照抄別人的信箱，也不用公開真實信箱。

## 3. 安裝工具

Windows 開啟「終端機」或 PowerShell，若有 winget，可逐行執行；安裝過的工具可跳過對應那行。

```powershell
winget install --id Git.Git -e --source winget
winget install --id GitHub.cli -e --source winget
winget install --id Microsoft.PowerShell -e --source winget
```

若出現系統管理員提示，依校方電腦使用規定處理；無權安裝時請教師或助教協助。
沒有 winget 時，改從官方網站下載：[Git for Windows](https://git-scm.com/downloads/win)、[GitHub CLI](https://cli.github.com/)、[PowerShell 7 安裝說明](https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell-on-windows)。Git 安裝選項可先使用預設值。

**安裝完關閉所有終端機，再從開始功能表開啟 PowerShell 7。** 不要選 Windows PowerShell 5.1；兩者名稱很像。

```powershell
$PSVersionTable.PSVersion
git --version
gh --version
```

驗收：第一個結果 Major 至少為 7；另外兩個結果有版本號。Git 建議使用目前版本，至少 2.28（支援本教材的 `init -b`）。出現「無法辨識」先看排錯手冊。

## 4. 登入 GitHub

```powershell
gh auth login --hostname github.com --git-protocol https --web
```

依畫面複製一次性驗證碼 → 在自己的瀏覽器登入 → 核對使用者名稱 → 貼上驗證碼 → 授權 GitHub CLI。
如果詢問是否使用 GitHub 認證來操作 Git，選 Yes。不要把一次性驗證碼貼到班級群組。

```powershell
gh auth setup-git
gh auth status
```

驗收：顯示已登入 github.com，且帳號是自己。不要把 `gh auth token` 當檢查指令，它會顯示憑證。

## 5. 取得教材並進到正確資料夾

教師發 ZIP 時：先解壓縮到自己的「文件」資料夾；不要在 ZIP 預覽視窗內操作。找到**同時包含 README.md、task-status.txt、docs** 的那一層資料夾，在檔案總管網址列輸入 `pwsh` 後按 Enter。

若教師把本教材放在 GitHub：先用瀏覽器到教師的儲存庫 → Code → Download ZIP，再解壓縮。這次從 ZIP 開始，讓每個人都親手執行 `git init`。**先不要 clone 教師庫再接著做 init／repo create**，那會帶入教師的 origin 與歷史。

```powershell
Get-Location
Get-ChildItem -Force
Get-Content -LiteralPath task-status.txt
Test-Path -LiteralPath .git
```

驗收：能看到教材檔案，狀態為 `todo`，最後顯示 `False`。若為 True，先停下，換一份全新解壓縮的副本；不用刪掉 `.git`。

## 6. 複製指令的規則

- 灰底區塊中的內容才是指令；不要複製 ```、`PS C:\...>` 提示字樣或預期輸出。
- `#` 開頭是註解，可以一起貼；每行通常按一次 Enter。
- 引號請保留英文半形，不要改成中文引號。
- `$name` 是變數。它只在目前終端機有效；關掉後重開，需要依手冊重新設定。
- `@'` 到 `'@` 是多行文字，必須整段貼上；最後的 `'@` 要從行首開始。
- 出現紅字或非預期結果，停止下一段，讀取錯誤訊息，不要反覆重貼整關。
- `git log`／`git diff` 若進入分頁畫面，按 `q` 離開；按空白鍵往下翻。
